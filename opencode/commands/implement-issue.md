---
description: Update main, implement one open GitHub issue, and submit a pull request
---

Switch to main, pull, and make sure it's clean. Then pick one item from this repository's open GitHub issues and implement it (not the Dependency Dashboard).

Check the working tree before switching branches. If there are existing changes, stop and ask how to handle them. Use a fast-forward-only pull and verify that main is clean and up to date before implementing the issue.

Use gh to inspect the issues and choose an actionable issue. Read the repository instructions, explain which issue you selected, implement it fully, and run the relevant checks. Summarize the changes and verification results with a link to the issue.

Finally, submit an MR (a pull request on GitHub). Create a feature branch for the implementation, review and commit the intended changes, push the branch, and use gh to create the pull request targeting main. Include a summary, verification results and any blockers, and a closing reference to the selected issue in the pull request description. Return the pull request URL.
